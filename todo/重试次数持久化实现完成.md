# ShardingKey 重试次数持久化功能实现完成

## 实现概述

根据文档要求，已成功实现了 ShardingKey 重试次数持久化功能，该功能基于 RocksDB 提供高性能的重试次数存储和管理。

### 1. ShardingKeyRetryStorage
- **位置**: `broker/src/main/java/org/apache/rocketmq/broker/offset/order/ShardingKeyRetryStorage.java`
- **功能**: 基于 RocksDB 的重试次数持久化存储管理器
- **特性**:
  - 高性能读写操作
  - 内存缓存优化
  - 异步写入策略
  - 失败容错处理

  - 重试次数增加时同步更新持久化存储

  - 提供统计信息监控

### 3. ShardingKeyLevelConsumerManager 启动集成

## 技术规格

### 存储设计
- **存储介质**: RocksDB
- **存储路径**: `$storePathRootDir/kvStore/shardingKeyRetry`
- **Key 格式**: `topic@group@queueId@shardingKey`
- **Value 格式**: int（重试次数）

### 性能优化
- **内存缓存**: 减少 RocksDB 读取频率
- **异步写入**: 提高写入性能，设置 `sync=false`
- **压缩算法**: 使用 Snappy 压缩减少存储空间
- **批量操作**: 支持批量读写操作

### 容错策略
- **失败不阻塞**: 持久化失败不影响主流程
- **读取回退**: 读取失败时回退为默认值 0
- **启动容错**: 存储启动失败时仅记录警告，不影响系统启动

## 生命周期管理

### 创建阶段
```java
// 创建锁时从持久化存储读取重试次数
ShardingKeyLock newLock = new ShardingKeyLock(popTime, lockFreeTimestamp, attemptId);
int persistedRetryTimes = retryStorage.getRetryTimes(topic, group, queueId, shardingKey);
newLock.setRetryTimes(persistedRetryTimes);
```

### 更新阶段
```java
// 增加重试次数时同步持久化
int newRetryTimes = lock.getRetryTimes() + 1;
lock.setRetryTimes(newRetryTimes);
retryStorage.setRetryTimes(topic, group, queueId, shardingKey, newRetryTimes);
```

### 清理阶段
```java
// 锁完全释放时清理持久化记录
if (lock.isEmpty()) {
    retryStorage.removeRetryTimes(topic, group, queueId, shardingKey);
    shardingKeyMap.remove(shardingKeyHash);
}
```
